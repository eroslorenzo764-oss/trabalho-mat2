Modelagem Matemática e Programação:
O Uso de Algoritmos na Inovação Tecnológica

Simulação de Reação em Cadeia — Progressão Geométrica aplicada em JavaScript

1. Introdução

A matemática é, historicamente, a linguagem que permite descrever e prever fenômenos do mundo real. Com o avanço da computação, essa linguagem ganhou um novo tradutor: a programação. Hoje, conceitos como progressões, matrizes, geometria analítica e estatística deixaram de existir apenas no papel e passaram a rodar em servidores, aplicativos e algoritmos que sustentam a inteligência artificial, a criptografia e a análise de grandes volumes de dados (Big Data).

Este trabalho tem como objetivo demonstrar, na prática, como um conceito matemático de crescimento exponencial pode ser traduzido em um algoritmo funcional. Para isso, será desenvolvida uma simulação computacional de reação em cadeia, modelo matemático amplamente utilizado não apenas em física, mas também em áreas como epidemiologia (espalhamento de doenças), marketing viral e crescimento populacional — mostrando como uma mesma estrutura matemática pode ser reaproveitada em contextos completamente diferentes.

2. Fundamentação Teórica

2.1 A Matemática como Linguagem da Inovação

Todo algoritmo é, no fundo, uma sequência de operações matemáticas organizadas em uma lógica de repetição e decisão. No caso deste trabalho, o conceito central é a progressão geométrica (PG): uma sequência em que cada termo é obtido multiplicando o anterior por uma razão fixa. Quando aplicamos uma taxa de probabilidade a cada "elemento ativo" de um sistema, obtemos uma variação probabilística da PG — o crescimento deixa de ser fixo e passa a depender de sorteios aleatórios, o que aproxima o modelo de fenômenos reais (nem todo contato gera contágio, nem toda reação se propaga).

2.2 O Papel da Programação

A programação entra como ferramenta de automação: em vez de calcular manualmente centenas de gerações de uma sequência, o computador executa milhares de iterações em milissegundos, permitindo testar diferentes cenários (taxas de ativação, número de gerações, condições de parada) e observar como pequenas mudanças nos parâmetros iniciais alteram drasticamente o resultado final — um exemplo prático de sensibilidade às condições iniciais.

3. Proposta de Aplicação Prática: Simulação de Reação em Cadeia

Conceito matemático: progressão geométrica probabilística (equação de diferenças discretas).
Inovação e tecnologia: o mesmo modelo usado aqui serve de base para simuladores de propagação de epidemias, análise de viralização de conteúdo em redes sociais e estudos de reações em cadeia na física nuclear — mostrando a versatilidade de um único algoritmo matemático.

A cada geração, cada elemento "ativo" tem uma probabilidade p de ativar n novos elementos. O número total de elementos ativos por geração segue, em média, a equação: 

ativos(g) ≈ ativos(g-1) × (n × p)

onde n × p é o "fator de multiplicação médio" do sistema.

4. Metodologia e Desenvolvimento do Código

O código abaixo foi construído em três partes:

  1. Uma função que simula a ativação de um elemento (sorteio de probabilidade);
  2. Um laço de repetição que avança geração por geração, aplicando a função anterior a cada elemento ativo;
  3. Uma coleta de dados (array) que guarda o total de ativos por geração, para depois gerar o gráfico/tabela.
// ==== SIMULAÇÃO DE REAÇÃO EM CADEIA ====
// Cada elemento ativo tem chance "probabilidade" de ativar "novosPorAtivacao" elementos

function simularReacaoEmCadeia(elementosIniciais, probabilidade, novosPorAtivacao, geracoes) {
  let ativos = elementosIniciais;
  const historico = [ativos]; // guarda o total de ativos em cada geração

  for (let g = 0; g < geracoes; g++) {
    let novosAtivados = 0;

    // cada elemento ativo "tenta" ativar novos elementos
    for (let i = 0; i < ativos; i++) {
      for (let j = 0; j < novosPorAtivacao; j++) {
        if (Math.random() < probabilidade) {
          novosAtivados++;
        }
      }
    }

    ativos = novosAtivados;
    historico.push(ativos);

    // condição de parada: se ninguém mais ativa, a reação "morre"
    if (ativos === 0) break;
  }

  return historico;
}

Função complementar 1 — taxa média de crescimento entre gerações:

// Calcula, em média, por quanto o número de ativos foi multiplicado
// a cada geração (razão média da progressão geométrica observada)
function taxaMediaDeCrescimento(historico) {
  let somaRazoes = 0;
  let contagem = 0;

  for (let i = 1; i < historico.length; i++) {
    if (historico[i - 1] > 0) { // evita divisão por zero
      somaRazoes += historico[i] / historico[i - 1];
      contagem++;
    }
  }

  return contagem > 0 ? somaRazoes / contagem : 0;
}

Função complementar 2 — reação com limite de recursos finitos:

// Versão da simulação com um teto máximo de elementos (ex: população total,
// estoque de material físsil, número de usuários possíveis de uma rede)
function simularReacaoComLimite(elementosIniciais, probabilidade, novosPorAtivacao, geracoes, limiteMaximo) {
  let ativos = elementosIniciais;
  const historico = [ativos];

  for (let g = 0; g < geracoes; g++) {
    let novosAtivados = 0;

    for (let i = 0; i < ativos; i++) {
      for (let j = 0; j < novosPorAtivacao; j++) {
        if (Math.random() < probabilidade) {
          novosAtivados++;
        }
      }
    }

    // trava no limite máximo de recursos disponíveis
    ativos = Math.min(novosAtivados, limiteMaximo);
    historico.push(ativos);

    if (ativos === 0 || ativos >= limiteMaximo) break;
  }

  return historico;
}

5. Considerações Finais

Ao rodar a simulação diversas vezes com diferentes valores de probabilidade, fica evidente que o comportamento do sistema não é gradual — ele muda de forma abrupta em torno de um valor específico. Quando a probabilidade multiplicada pelo número de novos elementos por ativação (p × n) é menor que 1, a reação tende a se extinguir rapidamente, já que cada geração produz, em média, menos elementos ativos que a anterior. Quando esse produto ultrapassa 1, o sistema entra em crescimento exponencial descontrolado, mesmo que a diferença nos parâmetros iniciais seja pequena. Esse ponto de transição é conhecido, em contextos físicos, como massa crítica, mas o mesmo princípio matemático aparece em qualquer fenômeno de propagação: para um vírus se espalhar em uma população, o número básico de reprodução (R0) precisa ser maior que 1; para um conteúdo "viralizar" nas redes sociais, cada pessoa que vê o post precisa, em média, compartilhá-lo com mais de uma outra pessoa.

Isso mostra a versatilidade da modelagem matemática como ferramenta de inovação: o mesmo algoritmo de progressão geométrica probabilística construído aqui poderia, com pequenos ajustes de contexto, ser reaproveitado por uma equipe de saúde pública simulando a propagação de uma doença, por uma empresa de marketing avaliando o potencial de viralização de uma campanha, ou por um analista de dados projetando o crescimento da base de usuários de um aplicativo. A programação não cria o conceito matemático — ela o transforma em uma ferramenta de simulação e previsão, permitindo testar cenários que seriam inviáveis de calcular manualmente.

A maior dificuldade na implementação foi justamente traduzir um conceito determinístico (a fórmula da progressão geométrica) para um modelo probabilístico: em vez de multiplicar diretamente por uma razão fixa, foi necessário simular, elemento por elemento, um "sorteio" de ativação usando Math.random(), o que aproxima o algoritmo do comportamento real — imprevisível no detalhe, mas previsível na tendência geral quando observado em larga escala. Esse é, talvez, o maior aprendizado do trabalho: a matemática oferece a estrutura teórica, mas é a computação que permite observar como o acaso e a probabilidade moldam o resultado final de um sistema complexo.
